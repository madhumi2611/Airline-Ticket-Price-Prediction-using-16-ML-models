# Airline-Ticket-Price-Prediction-using-16-ML-models
Airline ticket price is predicted using 16 ML models, to find out which one of them makes the best prediction. The dataset is obtained from Kaggle. 

**#Models implemented**
 -Linear Regression
- Ridge, Lasso, Elastic Net
- Decision Tree Regressor
- Random Forest Regressor
- Extra Trees Regressor
- XGBoost Regressor
- Gradient Boosting Regressor
- AdaBoost Regressor
- Bagging Regressor
- k-Nearest Neighbors
- Support Vector Regressor (SVR)

**Deep Learning**
- Multilayer Perceptron (MLP)
- Deep Neural Network (DNN)
- 1D Convolutional Neural Network (Shallow & Deep CNN)
